# Installation

## Recommended

Install through the Community Plugins section in Obsidian's settings.

## Manual Installation

1. Download the latest release files from the [Releases](https://github.com/benjaminezequiel/keep-the-rhythm/releases) section.
2. Create a folder at `/.obsidian/plugins/` named `keep-the-rhythm`.
3. Reload Obsidian.
4. Go to **Settings > Community Plugins** and enable "Keep the Rhythm".
